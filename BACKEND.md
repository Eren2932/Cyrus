# Control plane: инфраструктура и API

## Топология

```
[VPS-1: control plane]                 [VPS-2..N: ноды]
  Caddy (TLS)                            sing-box / xray
  Ktor Server + Postgres                 VLESS + Reality (443)
  Remnawave panel + API                  WS/XHTTP за CDN (резерв)
  webhooks платежей
```

**Control plane и ноды — всегда разные машины.** Забанят ноду — панель, платежи и выдача
подписок продолжат работать, клиент просто переключится на другую локацию.

## Стоимость и ёмкость

| Позиция | Цена/мес | Комментарий |
|---|---|---|
| VPS control plane | 200–400 ₽ | 2 vCPU / 2 ГБ достаточно |
| VPS нода (NL/DE/FI) | 200–500 ₽ | держит 30–60 активных пользователей |
| Домен | ~100 ₽ | нужен для TLS и подписок |

Себестоимость на пользователя при 50 активных: **5–10 ₽/мес**. Цена продажи: 150–250 ₽/мес.

## API (v1)

| Метод | Назначение |
|---|---|
| `POST /v1/auth/device` | регистрация устройства, выдача JWT |
| `POST /v1/auth/telegram` | привязка аккаунта |
| `GET  /v1/plans` | каталог тарифов |
| `POST /v1/orders` | создать заказ → вернуть URL внешнего чекаута |
| `POST /v1/webhooks/{provider}` | подтверждение оплаты → создание/продление юзера в панели |
| `POST /v1/activate` | активация кода на устройстве |
| `GET  /v1/me` | энтайтлмент: срок, трафик, лимит устройств |
| `GET  /v1/subscription` | персональная sub-ссылка (sing-box / base64) |
| `GET  /v1/nodes` | список локаций + приоритеты |
| `POST /v1/telemetry` | анонимная диагностика подключений |

## Правила

- Один пользователь = один UUID в панели. **Общие ключи не выдаём.**
- Лимит устройств проверяется на сервере, не в приложении.
- Sub-ссылка — единственное, что хранит приложение. Ключи в ней ротируются свободно.
- Платежи: ЮKassa / Cryptomus / Telegram Stars. Только внешний чекаут.
- Логов трафика нет. Храним: срок подписки, объём трафика, количество устройств.
